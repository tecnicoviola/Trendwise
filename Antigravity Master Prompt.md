## 1. Product context and claims policy

TRENDWISE compares **two independent signals** for **five colour trends in India**: **Butter Yellow, Burgundy, Chocolate Brown, Powder Blue, Sage Green**.

- **Dataset A — consumer interest:** Google Trends relative search interest, India, one comparison group, aggregated to monthly, last 36 complete months.
- **Dataset B — fashion audit:** a single-date snapshot of **50 products** (women's tops, New Arrivals, three retailers: 17 / 17 / 16).

Datasets are never merged into one score. The audit is **never forecast**. There is **no combined score T**.

**The app may say:** "relative search interest (0–100)", "observed in 8 of 50 products", "statistical extrapolation", "test error (MAE)", "Synthetic demonstration data". **The app must never say or imply:** demand, sales or growth for audit data; "search volume" for Google Trends values; guaranteed or accurate forecasts without test results shown; AI, computer vision, live data, social media analysis; synthetic data being real research. No retailer or stock images are bundled.

Audience: fashion students and independent designers in India. Language: English (UK spelling). Platform: desktop-first responsive web.

## 4. Statistics and forecasting specification

All constants live in `src/lib/config.ts` and are displayed on the Methodology page: WINDOW\_MONTHS 36, TEST\_MONTHS 6, HORIZON\_MONTHS 3, MIN\_MONTHS\_REGRESSION 12, MIN\_MONTHS\_EVALUATION 24, DIRECTION\_BAND 0.5, YOY\_BAND 5, YOY\_MIN\_BASE 5, R2\_WEAK 0.2, R2\_STRONG 0.5, VISIBLE\_MIN\_FREQ 10, VISIBLE\_MIN\_RETAILERS 2, WEEKS\_PER\_MONTH\_MIN 3, CONFIDENCE 0.95.

For a series y₁…yₙ with x = 1…n:

- **OLS:** x̄, ȳ; Sxx = Σ(x−x̄)²; b1 = Σ(x−x̄)(y−ȳ)/Sxx; b0 = ȳ − b1·x̄; ŷ = b0 + b1·x; SSE = Σ(y−ŷ)²; SST = Σ(y−ȳ)²; R² = 1 − SSE/SST (if SST = 0 return null and display "n/a"); s = √(SSE/(n−2)).
- **Normalised slope** = b1/ȳ × 100 (percent of mean per month); if ȳ = 0 the direction is "No signal". **Direction:** greater than +DIRECTION\_BAND = Increasing; less than −DIRECTION\_BAND = Decreasing; otherwise Stable (exactly ±0.5 is Stable). **Fit strength:** R² < 0.2 weak, 0.2–0.5 moderate, > 0.5 strong.
- **YoY** = (mean of last 3 months ÷ mean of the same 3 months 12 months earlier − 1) × 100; if the earlier mean < YOY\_MIN\_BASE return null ("n/a, base too small"); if fewer than 15 months exist return null. YoY direction: > +5 up, < −5 down, else flat. **Mixed-signals flag** when slope direction and YoY direction contradict (Increasing vs down, or Decreasing vs up).
- **Prediction interval** at x₀: ŷ₀ ± t·s·√(1 + 1/n + (x₀−x̄)²/Sxx), t = two-sided 95% critical value with n−2 degrees of freedom. Implement `tCritical(df)` in `src/lib/stats/tcrit.ts` with this exact table (95% two-sided): df 1: 12.706, 2: 4.303, 3: 3.182, 4: 2.776, 5: 2.571, 6: 2.447, 7: 2.365, 8: 2.306, 9: 2.262, 10: 2.228, 11: 2.201, 12: 2.179, 13: 2.160, 14: 2.145, 15: 2.131, 16: 2.120, 17: 2.110, 18: 2.101, 19: 2.093, 20: 2.086, 21: 2.080, 22: 2.074, 23: 2.069, 24: 2.064, 25: 2.060, 26: 2.056, 27: 2.052, 28: 2.048, 29: 2.045, 30: 2.042, 40: 2.021, 60: 2.000, 120: 1.980, infinity: 1.960. For df between table entries above 30, interpolate **linearly in 1/df**; above 120 use 1.960. (Check: df 34 gives about 2.032.) Guard s = 0 (zero-width band, no NaN).
- **Final forecast:** refit on **all** complete months (up to 36) and forecast the next HORIZON\_MONTHS months with the 95% prediction interval. Display values are clipped to 0–100; keep raw values in the data and in the CSV export (`raw` and `clipped` columns).
- **Evaluation** (only if n ≥ 24): test = last TEST\_MONTHS (6) months, training = all earlier months (30 when n = 36). Chronological, never shuffled. For each test month predict with: **OLS** fitted on training only and extended; **Persistence** = last training value repeated; **Seasonal-naive** = actual value 12 months earlier (must exist in the data). **MAE** = mean |actual − predicted| per model. Best model = strictly lowest MAE (if within 1e-9, report "tied"). Never claim OLS is good if a baseline beat it; the verdict text states which model won.
- **Rolling origin (extended check):** for n = 36, training end points 24 … 33 (10 origins), forecast 3 months ahead each time with all three models, average the MAE per model; shown in a collapsible "Extended evaluation" box.
- **Length rules:** n < 12: no regression, show a message; 12 ≤ n < 24: regression and forecast with a "short history" warning, no evaluation; n ≥ 24: everything.
- **Wilson interval** for k of n at z = 1.96: centre = (p + z²/2n)/(1 + z²/n); half = z·√(p(1−p)/n + z²/4n²)/(1 + z²/n). For k = 8, n = 50: lower about 0.0834, upper about 0.2851.

Output types in `src/types/forecast.ts`: `TrendAnalysis` containing the series, stats (mean, b0, b1, normalisedSlope, r2, s, direction, fit), yoy, forecast points (raw, clipped, lower, upper), evaluation (split, three models' predictions and MAE, verdict, rolling results) and warnings.

## 5. Audit analytics and Signal Alignment

For each trend, using the dictionary mapping (attribute `colour`): observed count k, frequency = k/n × 100, Wilson interval, retailer coverage (number of retailers with k ≥ 1, and the total number of retailers), per-retailer counts and sample sizes, and for the products of that colour the distribution of fabric, print and silhouette. Also overall attribute distributions and an "Other colours" group.

**Retail visibility:** Visible if frequency ≥ 10 **and** coverage ≥ 2 retailers; otherwise Low (includes not observed).

**Signal Alignment** (search direction × retail visibility):

- Increasing + Visible = **Aligned rise** (interest rising and already on shelves)
- Increasing + Low = **Emerging signal** (interest rising, little retail presence yet)
- Stable + Visible = **Established** (steady interest, well stocked)
- Stable + Low = **Quiet** (little signal on either side)
- Decreasing + Visible = **Fading interest, still stocked** (retail may lag search)
- Decreasing + Low = **Aligned decline** (interest falling and little on shelves)
- "No signal" direction = **Insufficient search signal**. Every alignment shows the sentence: "This compares two observations. It does not predict retail performance."
